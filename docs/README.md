## 维护约定

- 描述当前行为的文档放入 `guides/`、`reference/` 或 `architecture/`。
- 审计、调研和一次性分析放入 `research/`。
- 已完成的阶段报告、过时设计稿和旧状态快照放入 `archive/`。
- `archive/` 中的文档仅用于追溯，不作为当前规范；其中的路径和结论可能反映当时状态。
